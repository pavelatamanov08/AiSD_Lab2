## Лабораторная работа №2: Односвязный циклический связный список

## Автор

Павел Атаманов

## Вариант 
Список - 3
Задание - 4

## Описание

Шаблонный класс `LinkedList<T>` — Односвязный циклический список с полями
- `_end` - указатель на последний элемент списка
- `_size` - размер списка

Вспомогательная шаблонная структура `Node<T>` с полями
- `_value` - значение элемента списка
- `_next` - указатель на следующий элемент

## Возможности

- Конструкторы: с заполнением случайными значениями, конструктор по умолчанию, конструктор копирования

- Операторы: `=`, `[]`, `<<`

- Функции push_tail для добавления элемента или списка в конец текущего списка

- Функции push_head для добавления элемента или списка в начало текущего списка (порядок элементов добавляемого списка сохраняется)

- Функции pop_tail и pop_head для удаления элемента в конце или начале списка

- Функция delete_node для удаления всех элементов, в которых поле _value равно указанному значению

- Функция print_reverse для вывода на печать списка в обратном порядке
